# BOSY — The Timeless Birthday Universe ❤️ (بوسي)

An award-winning, cinematic, highly interactive birthday website and universe exclusively dedicated to **BOSY (بوسي)**, born **July 4, 2005 (04-07-2005)**.

---

## 🌟 Key Features

1. **The Secret Envelope (Signature Opening Interaction)**:
   - 3D-styled physical letter & envelope crafted in HTML/CSS with realistic perspective.
   - Wax seal with glowing heart.
   - Realistic 3D flap flip, rising parchment letter, and particle burst.
   - Smooth camera transition into the world.

2. **Smart Automatic Yearly Transformation Engine**:
   - Accurately computes Bosy's real age from her birth date (**July 4, 2005**).
   - Before July 4: displays current age and a countdown to her milestone.
   - On July 4: automatically activates that year's unique edition!
   - **Edition 2026**: `BLOOMING IN 21` (Rose Pink, Lavender, Champagne Gold, Garden Romance).
   - **Edition 2027**: `ANOTHER CHAPTER — 22` (Dark Luxury, Futuristic Romance, Electric Violet, Neon Pink, Cyber Flora).
   - **2028 & Beyond**: Procedural luxury generation (`CELESTIAL RADIANCE — 23`, `ROYAL EMERALD & VELVET — 24`, etc.).

3. **The Photography Experience**:
   - Uses the exact same two uploaded personal photographs:
     - `public/images/bosy-1.jpg`
     - `public/images/bosy-2.jpg`
   - **Photo 1**: Premium editorial frame with glowing animated border and delicate gold filigree.
   - **Photo 2**: Soft glassmorphism crystal frame with floating neon heart emitter.
   - Preserves facial integrity without distortion or AI replacement.

4. **The Emotional Arabic Birthday Letter**:
   - Custom parchment typography card with the heartfelt message for Bosy.
   - Interactive clickable wax seal with celebration burst.

5. **The Birthday Song Experience**:
   - Features Ahmed Moza's song (*"يفوت ألف سنة وأنا لسه زي ما أنا — مهرجان أنا من يومي خفاش"*).
   - Custom player: Play/pause, waveform visualizer, scrubber, volume control, rotating vinyl disc.
   - Plays `/audio/birthday-song.mp3` if placed in `public/audio/`.
   - Built-in soothing ambient music-box fallback melody using Web Audio API if no MP3 file is present.
   - Direct official listening links to YouTube and Anghami.

6. **Interactive Particle & Ambient Canvas Engine**:
   - 60 FPS Canvas particle system (floating petals, hearts, butterflies, stars).
   - Clicking background creates heart bursts.
   - Clicking the birthday number triggers special explosions.

7. **The Secret Surprise**:
   - Discreet glowing hidden easter egg that unlocks the secret quote:
     > *"في حاجات كتير حلوة في الدنيا، بس وجودك لوحده كفاية يخلي اليوم أحلى. ❤️"*

8. **Developer Theme Preview Toolbar**:
   - Floating panel in bottom-left corner with quick simulation presets:
     - 🌸 July 3, 2026 (Eve of 21)
     - 🎂 July 4, 2026 (Age 21 • Blooming in 21)
     - 🦋 July 3, 2027 (Eve of 22)
     - ⚡ July 4, 2027 (Age 22 • Another Chapter 22)
     - 👑 July 4, 2028+ (Age 23+ • Future Proof Procedural Universe)
     - ✉️ Replay Envelope animation at any time.

```bash

```

### Production Build:
```bash
npm run build
npm run preview
```

Place BOSY's two photos in:
